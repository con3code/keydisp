# KeyDisp

**macOS 用キーストローク・ビジュアライザ** — 押しているキーやマウスクリックを画面に大きく表示します。

**[con3code.github.io/keydisp](https://con3code.github.io/keydisp/)** · English documentation is available in [README.md](README.md).

KeyDisp はメニューバーに常駐し、キーボード入力をリアルタイムに表示します。学校の授業、
研修会、プレゼンテーション、スクリーンキャスト、ペアプログラミングなど、「いま何を
押したか」を見せたい場面のために設計されています。

## 機能

- **リアルタイムキー表示** — 押している間は表示し続け、離すと設定時間の保持後にフェードアウト
  （保持時間・フェード時間は調整可能）
- **修飾キー・特殊キー対応** — ⌘ ⌥ ⌃ ⇧ fn、矢印・Tab・Return・Esc・Delete・F1–F20 と
  それらのコンビネーション。fn なしで押した機能キー（Mission Control、輝度など）も
  F キー番号で表示
- **連続入力カウント** — 同じキーやショートカットの連打・長押しは `⌘V ×3` のように
  まとめて表示（パルスアニメーション付き）
- **マウス表示** — クリック / ドラッグ中のカーソル位置に円形ハイライト（左右ボタンで
  形状が変化、色・サイズ調整可）。修飾キー + クリックはキー表示にもカーソルマーク付きで表示
- **Windows 向け表記** — キー表記を Mac 記号 / Windows 表記（⌘/⌃ → Ctrl、⌥ → Alt、
  ↩ → Enter、⌫ → BackSpace など）/ 併存表示（`⌘/Ctrl`）から選択。Mac と Windows が
  混在する教室・研修に便利
- **日本語キーボード対応** — 英数/かな キー（新しい JIS 刻印に合わせて ABC/あいう 表記も
  選択可、🌐 マークのオプション付き）。かな入力ユーザー向けに、JIS かな配列のひらがなで
  表示するモードも搭載
- **自由なレイアウト** — オーバーレイはどのディスプレイへもドラッグで移動でき、
  表示編集モードで枠の端をドラッグして直接リサイズ。積み上げ方向（新しい行が下 / 上）と
  表示行数も選択可能。長い行は自動で折り返し
- **3 種類のスタイル** — シンプル文字 / キーキャップ風 / カスタム背景画像。
  文字色・背景色・背景の濃さも調整可能
- **表示編集モード** — フローティング HUD で、実際の表示を見ながらサイズ・色・行数・
  スタイルを調整
- **ホットエッジ** — 画面下端にカーソルを置いている間は表示を一時的に隠す
  （非表示中の入力は表示されません）
- **グローバルショートカット** — 表示/非表示をホットキーで切替え（デフォルト ⌥⌘K、変更可能）
- **日本語 / 英語 UI** — システム言語に追従、または手動で選択
- ログイン時に起動、メニューバー / Dock アイコンの表示切替え、初回起動時の権限設定ガイド

## インストール

1. [Releases](../../releases) から最新の `KeyDisp-vX.Y.Z.zip` をダウンロードして展開します。
2. `KeyDisp.app` を `/Applications` フォルダへ移動して開きます。

リリースのバイナリは Developer ID 証明書で署名し、Apple の公証（notarization）を
受けているため、Gatekeeper の警告なしで開けます。

詳しい使い方と全設定項目の説明は **[ユーザーマニュアル](docs/MANUAL.ja.md)** を
ご覧ください。

### 初回起動 — 権限の設定

KeyDisp は macOS のアクセシビリティ API 経由でキー入力を読み取ります。初回起動時に
ガイド画面が案内します:

1. **システム設定 › プライバシーとセキュリティ › アクセシビリティ** で KeyDisp をオン
   （**必須**）
2. **システム設定 › プライバシーとセキュリティ › 入力監視** に KeyDisp があればオン

重要なのはアクセシビリティのほうです。入力監視の一覧には KeyDisp が表示されないことが
よくありますが（macOS はアクセシビリティ権限がこれを兼ねるものとして扱います）、
それで正常です。画面にキーが表示されていれば問題ありません。

アクセシビリティの一覧に KeyDisp が表示されない場合（再インストール後など）は、
アプリの **設定 → 権限** のボタンを押すと一覧に再登録されます。

## 動作環境

- macOS 13 Ventura 以降（Apple シリコン / Intel）

## ソースからのビルド

Xcode 15 以降と [XcodeGen](https://github.com/yonaskolb/XcodeGen)
（`brew install xcodegen`）が必要です:

```bash
xcodegen generate
xcodebuild -project KeyDisp.xcodeproj -scheme KeyDisp -configuration Release build
```

または生成された `KeyDisp.xcodeproj` を Xcode で開いて実行してください。

配布用 zip を `dist/` に作るには:

```bash
./scripts/release.sh
```

## Mac App Store で配信しない理由

App Store への提出には App Sandbox が必須ですが、サンドボックスは KeyDisp がキー入力の
監視に使うグローバルイベントタップを禁止しています。これはすべてのキーストローク表示
アプリに共通するプラットフォーム上の制約のため、KeyDisp は直接配布しています。

## プライバシー

KeyDisp の仕事は入力を画面に表示することだけです。入力の記録・保存・送信は一切行いません。
アプリはネットワークにアクセスしません。
