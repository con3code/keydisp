KeyDisp

押したキーが、
そのまま伝わる。

Every key you press,
on screen.

KeyDisp は macOS のメニューバーに常駐し、キーボード操作とマウスクリックを 画面に大きく表示します。授業・研修・プレゼン・スクリーンキャストのために作りました。

KeyDisp lives in your macOS menu bar and shows your keystrokes and clicks, large and legible. Built for classrooms, training, presentations, and screencasts.

表示のしくみHow it reads

見せたいものだけが、読める速さで残る

Only what matters, at a readable pace

01

押している間は出したまま

Held while you hold it

キーを押している間はずっと表示されます。長押しの実演もそのまま伝わります。

A key stays on screen as long as you hold it, so held-key demos read correctly.

02

離しても少し残る

Lingers after release

離したあと設定した秒数だけ残り、ゆっくり消えます。見逃されません。

After release it holds for a set time, then fades — no one misses it.

03

連打は ×n にまとまる

Repeats collapse into ×n

同じ操作の連打や長押しリピートは行を増やさず「⌘V ×3」と回数で示します。

Repeated presses and key repeats become a count like ⌘V ×3 instead of new rows.

04

タイピングは既定で出さない

Plain typing stays quiet

既定ではショートカットと特殊キーだけ。文字入力も見せたいときは設定で切り替えます。

By default only shortcuts and special keys appear. Turn on plain typing when you want it.

Mac と WindowsMac & Windows

Windows の受講者にも、押すキーが伝わる

Windows learners see the key they should press

キー表記を Windows 名に切り替えられます。対応はショートカット互換 ——Mac で ⌘C を押すと、画面には Ctrl+C と出ます。両方を並べる併存表示もあります。

Switch the labels to Windows names. The mapping is shortcut-equivalent: press ⌘C on the Mac and the display reads Ctrl+C. A combined mode shows both.

日本語キーボードJapanese keyboards

JIS 配列のことも、ちゃんと考えました

Built with JIS keyboards in mind

刻印に合わせて［英数］［かな］を［ABC］［あいう］表記に切り替えられます。 入力切替キーには 🌐 を付けて文字入力と区別でき、かな入力の方は JIS かな配列のひらがなで表示することもできます。

Show the 英数/かな keys as ABC/あいう to match newer keycaps, mark input-switch keys with a globe so they never look like typed letters, and — for kana typists — display keys as JIS-layout hiragana.

背景をつくるBackgrounds

好きな画像を、歪ませずに背景にできる

Your own artwork, stretched without distortion

背景画像は9 分割で引き伸ばします。画像を縦横 3 等分し、四隅は比率を 保ったまま、上下の中央は横に、左右の中央は縦に、中央だけ縦横に伸びる方式です。 長いコンビネーションで横に広がっても、折り返して 2 行になっても、角の丸みや枠の 太さはそのまま保たれます。すぐ使えるサンプルを 5 種類用意しました （画像をクリックすると 1 枚ずつ、下のボタンでまとめてダウンロードできます）。

Background images stretch as a nine-slice: cut into thirds on both axes, the corners keep their proportions, the top and bottom edges stretch only horizontally, the sides only vertically, and the centre fills the rest. Rounded corners and border weights survive a wide row or a wrapped one. Five ready-made backgrounds are waiting below — click one to download it, or take the whole set.

できることFeatures

画面に合わせて、細かく決められる

Tuned to fit your screen

好きな位置と大きさ

Place it anywhere

表示編集モードでドラッグして移動、枠の端で直接リサイズ。マルチディスプレイ対応で位置も記憶します。

Drag to move, drag the edges to resize, across any display. Position and size are remembered.

3 つのスタイル

Three styles

シンプル文字・キーキャップ風・9 分割で伸びる背景画像。文字色も背景の濃さも自由です。

Simple text, keycap look, or a nine-sliced background image — with full color and opacity control.

マウスも見える

Clicks, too

クリックとドラッグをカーソル位置の円で示し、⌘ + クリックはキー表示にも並べます。

A circle marks clicks and drags at the cursor; ⌘ + click also appears in the key display.

大きいマウスカーソル

A larger pointer

カーソルに追従する大きなポインタを重ねられます。色と大きさは自由に調整できます。

Overlay a large pointer that follows the cursor, in the size and color you choose.

すぐ隠せる

Hide it instantly

⌥⌘K で切り替え。カーソルを画面の下端に置いている間は隠し、上端に置いている間は履歴を消さずに残せます。

Toggle with ⌥⌘K. Park the cursor at the bottom edge to hide the display, or at the top edge to keep the history from fading.

積み上げ / ぶら下がり

Stack or hang

新しい行を下から積むか、上から下げるか。表示する行数も 1〜8 行で選べます。

New rows can stack up from the bottom or hang down from the top, 1–8 rows deep.

押した順に見せられる

Show the order you press

修飾キーを実際に押した順で並べられます。区切りの判定時間も調整でき、手順の説明がそのまま伝わります。

Modifiers can appear in the order you actually pressed them, with an adjustable timing for when a release splits the row.

⌥ で入る記号も伝わる

⌥ symbols, spelled out

「⌥E → ´」のように、⌥ で入力される記号やアクセントを併記できます。連続する矢印キーのまとめ方も選べます。

Combinations like ⌥E can show the character they type — “⌥E → ´”. Arrow keys can group into one row, too.

日本語 / 英語 UI

Japanese / English UI

アプリの表示言語を切り替えられます。ログイン時の自動起動にも対応。

Switch the app's own language, and have it launch automatically at login.

入手するGet it

ダウンロードして、開くだけ

Download and open

zip を展開して KeyDisp.app をアプリケーションフォルダへ。 配布バイナリは Developer ID で署名し Apple の公証を受けているので、警告なしで開けます。

Unzip and move KeyDisp.app to your Applications folder. Builds are signed with a Developer ID certificate and notarized by Apple, so they open without warnings.

最新版をダウンロードDownload the latest release マニュアル User manual

初回起動時に入力監視の許可が必要です。キー入力の読み取りに使います。 KeyDisp は入力を記録も送信もせず、ネットワークにも接続しません。

On first launch KeyDisp asks for the Input Monitoring permission, which it uses to read keyboard input. It never logs or transmits anything, and never touches the network.
