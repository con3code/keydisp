# KeyDisp ユーザーマニュアル

[English version](MANUAL.en.md)

KeyDisp は、押しているキーやマウス操作を画面に大きく表示する macOS 用アプリです。
このマニュアルでは、インストールから各設定項目の詳細までを説明します。

## 1. インストールと初回起動

### インストール

1. [Releases](https://github.com/con3code/keydisp/releases) から最新の
   `KeyDisp-vX.Y.Z.zip` をダウンロードして展開します。
2. `KeyDisp.app` を `/Applications` フォルダへ移動して開きます。

リリースのバイナリは Developer ID 署名と Apple の公証（notarization）を受けているため、
警告なしで開けます。

### 権限の設定

KeyDisp はキー入力を読み取るために macOS の許可が必要です。
初回起動時に「KeyDisp の初期設定」ガイドが表示されるので、案内に従ってください。

1. **アクセシビリティ**（必須） — システム設定 › プライバシーとセキュリティ ›
   アクセシビリティ で KeyDisp をオン
2. **入力監視** — システム設定 › プライバシーとセキュリティ › 入力監視 に KeyDisp が
   あればオン

許可されるとガイドが自動的に閉じ、キー表示が始まります。

> **入力監視の一覧に KeyDisp が無くても大丈夫です**
>
> キー監視に実際に効いているのはアクセシビリティ権限で、macOS は入力監視の権限を
> それが兼ねるものとして扱います。そのため、アクセシビリティを許可した環境では
> 入力監視の一覧に KeyDisp が現れないことがよくあります（アプリの設定画面では
> 「許可済み」と表示されます）。画面にキーが表示されていれば正常な状態です。

> **ヒント**: アクセシビリティの一覧に KeyDisp が見つからない場合は、ガイドまたは
> 設定画面の「設定を開く / システム設定を開く」ボタンを押してください。押すと macOS へ
> 権限を再リクエストし、一覧に KeyDisp が（オフの状態で）追加されます。

### 起動するとどうなるか

KeyDisp はメニューバー常駐型のアプリです。起動するとメニューバーに ⌨ アイコンが現れます。
通常のウィンドウは開きません。すべての操作はメニューバーのアイコンから行います。

## 2. 基本的な使い方

### メニューバーメニュー

⌨ アイコンをクリックすると次のメニューが開きます。

| 項目 | 説明 |
|---|---|
| キー表示 | キー表示のオン / オフを切り替えます（チェックマークが現在の状態） |
| 表示編集モード | 表示の位置・サイズ・デザインをその場で調整するモードに入ります |
| 表示位置をリセット | オーバーレイをメイン画面の左下・標準サイズに戻します |
| 設定… | 設定画面を開きます（⌘,） |
| KeyDisp について | バージョン情報を表示します |
| ログイン時に起動 | Mac へのログイン時に KeyDisp を自動起動します |
| Dock にアイコンを表示 | Dock アイコンの表示 / 非表示を切り替えます |
| KeyDisp を終了 | アプリを終了します（⌘Q） |

メニューバーアイコン自体の表示 / 非表示は、設定画面の「一般」で切り替えます。
権限の状態確認は設定画面の「権限」で行えます（権限が足りないときは案内画面が自動で開きます）。

> **メニューバーと Dock の両方を非表示にはできません**。もし表示手段を失った場合は、
> Finder や Launchpad から KeyDisp をもう一度開くと設定画面が表示されます。

### 表示 / 非表示のショートカット

デフォルトでは **⌥⌘K** でキー表示のオン / オフを切り替えられます。
ショートカットは設定画面の「ショートカット」で変更できます。

## 3. キー表示の見かた

### 表示されるもの

デフォルト設定では、次の入力が表示されます。

- **修飾キー付きのコンビネーション** — ⌘C、⌃⌥T、⌘⇧S など
- **特殊キーの単独押下** — ↩ (Return)、⇥ (Tab)、⎋ (Esc)、⌫ (Delete)、矢印、F1〜F20 など
- **修飾キーの単独押下** — ⌘ ⌥ ⌃ ⇧ fn、⇪ (Caps Lock)
- **修飾キー + マウスクリック** — ⌘ + クリック など（カーソル型のマークで表示）

通常のタイピング（修飾キーなしの英数字など）は、既定では表示されません。
表示したい場合は設定の「**すべてのキー入力を表示**」をオンにしてください。

### 表示のライフサイクル

1. キーを押している間は表示され続けます
2. キーを離すと「**表示の持続時間**」のあいだ表示が残ります
3. その後「**フェードアウトの長さ**」をかけて徐々に消えます

新しい入力があると、行が積み上がっていきます（方向は設定で変更可能）。
表示できる行数を超えると、古い行から順に消えます。

### 連続入力のまとめ表示（×n）

同じキーやショートカットを連続して押すと、行を増やす代わりに
「⌘V ×3」のように回数がカウントされます（既定でオン）。

- キーを押しっぱなしにしたときのリピート（⌫ 長押しなど）も同じカウントに含まれます
- カウントが増える瞬間、行が軽く弾むアニメーションで合図します
- 間に別の入力が挟まった場合はまとめず、新しい行として表示します

### 主な記号の意味

| 記号 | キー | 記号 | キー |
|---|---|---|---|
| ⌘ | コマンド | ↩ | Return |
| ⌥ | オプション | ⇥ | Tab |
| ⌃ | コントロール | ⎋ | Esc |
| ⇧ | シフト | ⌫ | Delete（バックスペース） |
| ⇪ | Caps Lock | ⌦ | 前方削除（fn+Delete） |
| fn | ファンクション | ␣ | スペース |
| ↖ / ↘ | Home / End | ⇞ / ⇟ | Page Up / Page Down |

## 4. 表示編集モード

メニューバー →「表示編集モード」で、実際の表示を見ながら調整できます。

### できること

- **移動** — 破線の枠の内側をドラッグすると、オーバーレイを画面上の好きな場所へ
  動かせます。別のディスプレイへの移動も可能です。位置は記憶されます
- **リサイズ** — 破線の枠の**端**をドラッグすると、表示領域の大きさを直接変えられます。
  行の折り返し位置も幅に追従します
- **HUD パネルでの調整** — 画面右上に表示される「表示編集モード」パネルで、
  スタイル・サイズ・行数・積み上げ方向・色・背景をリアルタイムに変更できます

編集中はサンプルのキー表示（コンビネーション・タイピング・×n・クリックの例）が
表示されるので、実際の見た目を確認しながら調整できます。

終了するには HUD の「完了」ボタン、パネルの閉じるボタン、またはメニューバーから
再度「表示編集モード」を選びます。

## 5. 設定リファレンス

メニューバー →「設定…」で設定画面を開きます。

### 表示

| 項目 | 説明 |
|---|---|
| すべてのキー入力を表示 | オンにすると通常のタイピング（英数字など）も表示します。オフ（既定）ではコンビネーションと特殊キーのみ |
| 同じキーの連続入力を ×n でまとめる | 連打・長押しリピートを回数表示にまとめます（既定オン） |
| サイズ | キー表示の大きさ（×0.5〜×5.0） |
| 表示の持続時間 | キーを離してから表示が残る秒数（0〜5秒） |
| フェードアウトの長さ | 消えるまでのフェード時間（0.1〜4秒） |
| 表示の行数 | 同時に表示する最大行数（1〜8行） |
| 新しい入力を上に表示（ぶら下がり式） | オンで上端基準（新しい行が上）、オフで下端基準（新しい行が下） |
| 画面の下端にカーソルを置いている間はキー表示を隠す | ホットエッジ機能。下端（10px以内）にカーソルがある間は表示を隠し、その間の入力も表示しません |

### デザイン

| 項目 | 説明 |
|---|---|
| キーのスタイル | シンプル（文字のみ）/ キーキャップ（キー風の描画）/ カスタム画像 |
| 文字色 | キー表示の文字色 |
| キー / 背景色 | キーキャップや背景の色 |
| 背景を表示 | 背景の有無 |
| 背景の濃さ | 背景の不透明度（0〜100%） |
| カスタム背景画像 | 「カスタム画像」スタイル選択時に、キー表示の背景として使う画像を指定します。すぐ使えるサンプルが [Samples/Backgrounds](../Samples/Backgrounds) にあります |

背景画像は **9 分割（ナインパッチ）** で引き伸ばされます。画像を縦横 3 等分し、四隅は
比率を保ったまま、上下の中央は横に、左右の中央は縦に、中央は縦横に伸びるので、
表示が横に広がったり複数行に折り返しても角や枠が歪みません。自作する際のコツは
[Samples/Backgrounds/README.md](../Samples/Backgrounds/README.md) を参照してください。

### キー表記

| 項目 | 説明 |
|---|---|
| 表記スタイル | **Mac**: ⌘ ⌥ ↩ などの記号 / **Windows**: Ctrl、Alt、Enter など / **Mac + Windows**: 「⌘/Ctrl」のような併存表示 |
| 「英数/かな」を「ABC/あいう」と表示 | 新しい JIS 配列キーボードの刻印に合わせた表記にします |
| 入力切替キーに 🌐 を付ける | 英数/かな（ABC/あいう）キーに地球儀マークを付けて、通常の文字入力と区別しやすくします |
| かな入力（JIS かな配列）をひらがなで表示 | **かな入力ユーザー向け**。日本語入力モード中のタイピングを JIS かな配列のひらがな・記号で表示します。ローマ字入力の方はオフのままにしてください |
| キーの間に「+」を表示 | コンビネーションを Ctrl+Shift+S のように区切ります |
| 英字の大文字/小文字を区別して表示 | オンにするとタイピング表示が実際の入力どおり（Shift・Caps Lock を反映）になります。オフ（既定）では常に大文字 |

**Windows 表記の対応表**: ⌘/⌃ → Ctrl、⌥ → Alt、⇧ → Shift、↩ → Enter、
⌫ → BackSpace、⌦ → Delete、⎋ → Esc、英数 → 無変換、かな → 変換 など。
「Mac で ⌘C を押すと、Windows の受講者には Ctrl+C として伝わる」ショートカット互換の
対応付けです（⌃ と ⌘ を同時に押した場合、Ctrl の重複は 1 つにまとまります）。

### マウス

| 項目 | 説明 |
|---|---|
| クリック / ドラッグをカーソル位置に表示 | クリックの瞬間とボタンを押している間、カーソル位置に円を表示します。左クリック = 塗りつぶし、右クリック = 二重リング |
| ハイライトの色 / 大きさ | 円の色と直径（30〜120px） |
| 修飾キー + クリックをキー表示に出す | ⌘ + クリックなどをキー表示にもカーソルマーク付きの行として表示します |

### ショートカット

「表示 / 非表示の切替え」のボタンを押し、登録したいキーの組み合わせを押すと
記録されます（esc でキャンセル）。修飾キーを含まない組み合わせは登録できません。

### 一般

| 項目 | 説明 |
|---|---|
| 言語 | システム標準 / 日本語 / English。切替えは即時反映されます |
| ログイン時に起動 | Mac へのログイン時に自動起動します |
| メニューバーにアイコンを表示 / Dock にアイコンを表示 | 各アイコンの表示切替え（両方非表示は不可） |

### 権限

アクセシビリティと入力監視の許可状態が表示されます。

- **システム設定を開く** — 権限を再リクエストしてシステム設定を開きます。
  一覧に KeyDisp が無い場合の再追加にも使えます
- **再確認** — 権限の状態を確認し直し、キー監視を再起動します。
  「許可済み」と表示されているのにキーが出ないときに試してください

なお、入力監視が「許可済み」と表示されていてもシステム設定の一覧に KeyDisp が
見当たらないことがありますが、アクセシビリティ権限がその役割を兼ねているためで、
問題ではありません。

## 6. 活用のヒント

- **授業・研修（Mac / Windows 混在）** — 表記スタイルを「Windows」または
  「Mac + Windows」にすると、Windows の受講者にも操作が伝わります。
  「+」区切りも合わせてオンにすると読みやすくなります
- **プレゼン・スクリーンキャスト** — サイズを大きめ（×2〜×3）にし、
  表示の行数を 2〜3 行に抑えると画面がすっきりします
- **速いデモで表示が詰まるとき** — 持続時間とフェードを短くする、
  行数を減らす、×n まとめをオンにする、のいずれかで緩和できます
- **一時的に隠したいとき** — ⌥⌘K のショートカット、またはホットエッジ
  （カーソルを画面下端へ）を使うと、メニューを開かずに表示を消せます
- **画面上部に表示したいとき** — 「新しい入力を上に表示（ぶら下がり式）」をオンにすると、
  上端基準の自然な表示になります

## 7. トラブルシューティング

### キーが表示されない

1. メニューバーに ⌨ アイコンがあるか確認してください（無ければアプリが起動していません）
2. メニューの「キー表示」にチェックが付いているか確認してください
3. 設定 → 権限 で両方が「許可済み」になっているか確認してください
4. 許可済みなのに表示されない場合は、権限セクションの「**再確認**」ボタンを
   押してください（キー監視を再起動します）
5. それでも直らない場合は、システム設定の一覧から KeyDisp を削除（− ボタン）し、
   アプリの「システム設定を開く」ボタンで再追加 → トグルをオンにしてください

### システム設定の「入力監視」に KeyDisp が表示されない

問題ありません。キー監視に効いているのはアクセシビリティ権限で、macOS は入力監視を
それが兼ねるものとして扱うため、入力監視の一覧に項目が作られないことがよくあります。
アクセシビリティが許可されていて、画面にキーが表示されていれば正常です。

### 再インストール後に動かない

以前の権限項目が残っていると、トグルがオンに見えても実際には効いていないことが
あります。上記 5. の手順（削除 → 再追加）で解決します。

### 通常のタイピングが表示されない

仕様です。「すべてのキー入力を表示」をオンにしてください（設定 → 表示）。

### F7〜F12 の音量・再生キーが表示されない

これらのメディアキーは通常のキーボードイベントとは別の仕組みで送られるため、
現在のバージョンでは表示されません。

### 「key123」のような表示が出る

対応表にないキーコードのフォールバック表示です。お使いのキーボード固有のキーの
可能性があります。[Issues](https://github.com/con3code/keydisp/issues) で番号とともに
報告いただければ対応します。

## 8. よくある質問

**Q. App Store にはありませんか？**
A. ありません。App Store 必須の App Sandbox がキー入力の監視を禁止しているためです。
これはすべてのキーストローク表示アプリに共通する制約です。

**Q. 入力内容が記録・送信されることはありませんか？**
A. ありません。KeyDisp の仕事は画面に表示することだけで、入力の保存・送信は一切行わず、
ネットワークにもアクセスしません。

**Q. パスワード入力も表示されてしまいますか？**
A. macOS のセキュア入力（パスワード欄）中はシステムがキーイベントの配信を保護するため、
通常は表示されません。ただし確実を期すなら、パスワード入力時は ⌥⌘K で表示を
オフにすることをおすすめします。

**Q. ローマ字入力なのに「かな表示」をオンにしたらおかしくなりました**
A. かな表示は「かな入力」ユーザー専用のオプションです。macOS からは入力方式を
判別できないため、ローマ字入力の方はオフのままにしてください。

## 9. アンインストール

1. メニューバーから「KeyDisp を終了」
2. `/Applications/KeyDisp.app` をゴミ箱へ
3. （任意）システム設定 › プライバシーとセキュリティ の「アクセシビリティ」と
   「入力監視」から KeyDisp を削除
4. （任意）設定ファイルの削除: `~/Library/Preferences/dev.rin.KeyDisp.plist`
